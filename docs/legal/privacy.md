# プライバシーポリシー

最終更新日: 2026-11-18

Discord Bot「FORGE」（以下「本 Bot」）における情報の取り扱いについて
定めます。

## 1. 取得する情報

本 Bot は、機能の提供に必要な範囲で、次の情報を保存します。

- サーバー（ギルド）ID、チャンネル ID、ユーザー ID
- 管理者およびメンバーが作成した Blueprint の定義（コマンド名、
  返信テンプレート、Trigger の設定等）
- Blueprint の実行に伴うカウンター値、変数値、実行回数
- リアクション自動化の発火済み記録（メッセージ ID）
- スケジュール自動化の最終実行時刻
- 記憶機能に登録された内容（管理者が `/forge memory propose` で
  明示的に登録し、承認した内容）
- プラグインの有効化状態等のギルド設定

メッセージ本文そのものは、上記の定義や記憶として登録されたものを除き、
保存しません。

## 2. 利用目的

取得した情報は、本 Bot の機能提供（Blueprint の保存・実行、自動化の
発火管理、記憶の参照）のためにのみ利用します。

## 3. 第三者提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。

## 4. データの管理と削除

データはギルド（サーバー）ごとに分離して保存します。サーバーの
管理者は、本 Bot のデータ管理機能（`/forge data export` /
`/forge data delete`）により、自サーバーのデータをいつでも書き出し、
および全件削除できます。本 Bot をサーバーから削除（キック）した場合も、
同じ手順で削除を依頼できます。

## 5. お問い合わせ

本ポリシーに関するお問い合わせは、本 Bot の配布元リポジトリの
Issue からお願いします。
